# 产品编码表单规则采集器

这是一个本地 Chromium 扩展，用于在 VPN 内网环境中采集产品编码申请页面的表单结构和校验规则。

采集数据只保存在当前浏览器的扩展本地存储中，直到你导出或清空。扩展不发送网络请求。

当前版本为 `0.7.0`，已支持采集顶层门户中的 iframe 业务页面，可暂存 iView、Element 和 Ant Design 自定义下拉框曾经显示过的选项，并包含一次只操作一个字段的回填测试。回填会在页面主运行环境中执行，延迟检查前端框架是否保留了结果，并使用兼容 Dia 的两次点击确认。下拉选项会去重后同时写入对应字段的 `fields[].options` 和独立的 `observedOptionSets`。

## 采集内容

- 字段标签、控件类型、必填状态、禁用和只读状态
- 原生下拉选项和当前已打开的自定义下拉选项
- 字段帮助文字、校验错误、页面级提示
- 当前页面中的操作按钮文字
- 可选的当前可见区截图

## 明确不采集

- input、textarea、选择器的当前填写值
- password 和 hidden 输入控件
- Cookie、Token、localStorage、sessionStorage
- 网络请求、请求头或返回数据
- URL 的域名、查询参数和 hash；只保留 pathname

## 安装

### Chrome

1. 在地址栏输入 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个 `product-code-form-capture-extension` 文件夹。
5. 在扩展菜单中将“产品编码表单规则采集器”固定到工具栏。

如果已安装旧版，请在扩展管理页点击“重新加载”，然后刷新内网业务页。

浏览器会提示该扩展可读取 HTTP/HTTPS 页面。这是为了读取与顶层门户不同域的 iframe。扩展没有后台脚本或自动内容脚本，只有用户点击“采集当前状态”时才会执行。

### Edge

1. 在地址栏输入 `edge://extensions/`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择整个 `product-code-form-capture-extension` 文件夹。

## 建议采集流程

1. 安装扩展，然后连接 VPN。
2. 使用测试账号打开空白的产品编码申请页。
3. 点击扩展，将当前状态命名为“初始空白页”，然后采集。
4. 依次切换并采集：
   - 自研类 + 标准硬件
   - 自研类 + 平台服务
   - 自研类 + 标准软件
   - 生态类 + 标准硬件
   - 强研发管理
   - 弱研发管理
5. 首先采集一次当前页，让页面内的本地选项观察器开始工作。
6. 关闭插件弹窗，依次打开每个自定义下拉框，等待选项出现。不必选中选项。
7. 全部下拉框打开过一遍后，再打开插件采集。采集结果会显示已记录的“下拉选项组”数量。
8. 依次打开“基础信息、入库信息、通信方式、产品参数、海外推广条件、支撑团队、附件信息”等页签，每个页签至少采集一次。
9. 在测试表单上点击提交，显示校验错误后，命名为“空表提交校验”并采集。
10. 如果能打开审批页，分别采集待审批、驳回和审批通过的页面状态。
11. 点击“导出 ZIP 采集包”。
12. **在仍连接 VPN 时解压并人工检查 ZIP**，确认没有不应带出的信息。
13. 退出 VPN，恢复 Codex 后上传经确认的 ZIP。

## 截图说明

截图功能默认关闭。启用后，扩展会在截图前临时将常见 input、textarea、编辑区和选择器的文字设为透明，截图后立即恢复。

这不能保证遮住所有自定义组件。建议仅在空白测试表单上使用，并在导出后检查图片。

## 单字段回填测试

1. 只在测试申请单或确认不会提交的页面上运行。
2. 先采集当前页，让插件获得当前字段列表和 iframe 位置。
3. 在“单字段回填测试”中选择一个可编辑字段。
4. 普通文本框输入无敏感的测试内容；单选项不需输入；自定义下拉框输入完整的选项文字。
5. 点击“仅回填该字段”，然后在 8 秒内再点击一次“再次点击确认回填”。
6. 在页面上目视检查字段、校验状态和关联字段。
7. 不要点击“暂存”、“提交”、“生成编码”或审批按钮。完成后刷新或取消当前测试。

回填测试不会将输入的测试内容写入采集包。

## 已知局限

- 已支持 iframe，但浏览器或企业策略禁止注入的特殊页面仍可能无法读取。
- 自定义下拉框通常只在打开时将选项渲染到页面。需要先执行一次采集启动观察器，再在页面内打开下拉框。
- 下拉选项同时保存在对应字段的 `options` 和状态级 `observedOptionSets`；界面显示的是去重后的选项组数。
- 远程搜索或虚拟滚动下拉框只能记录实际加载过的选项。如果需要全部选项，需在下拉框中滚动或输入搜索词，让选项真正出现。
- 完全自定义、没有语义化标记的控件可能无法自动关联标签。
- 如果企业策略禁止“加载已解压的扩展”，需要由 IT 管理员授权或统一签名发布。
