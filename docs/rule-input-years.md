# 规则指定取数年份

## 优先级

1. 摘要明确写“取2024年的收入与增幅”时，读取2024年收入和2023年同比基数，即使批次年度为2025或2026。
2. 只有仍使用“当年／上年”等相对表述且没有明确年份的自定义规则，才按批次年度解释。不能以电脑当前年份或文件中最新年份替代规则年份。
3. 同一模型不同指标可指定不同年份；同一指标的同比仍要求指定年与上一年相邻，无法执行的混合年度含义必须确认。

## 默认摘要

新建模型的预设摘要使用创建时上一自然年度的具体年份。例如2026年创建时写明2025年，收入增幅公式同时写明2024年基数。具体年份保存后固定，不在每次打开页面时滚年；复制已含明确年份的模型时保留原年份，由用户决定是否修改。

存量模型仅对完全匹配内置预设的摘要补全年份，不覆盖自定义文字或自定义成本清单。已关联批次的模型优先沿用其唯一历史数据年度，未关联的已发布模型沿用原模型年度，草稿默认上一自然年度。若一个旧相对预设已经服务过多个不同年度的批次，则不自动选定单一年份，保留原配置，复制后再明确年份。

这项一次性迁移记录模型变更事件，并在事件中保存原定义；不改发布状态、不重算或覆盖已保存的评分结果。

## 一致性与缺失

模型所需字段、规则匹配、按需 AI 映射、本地缺失校验、评分计算使用指标自己的取数年份。追溯记录保存 data_year，结果页明细和 Excel 表头据此生成；批次名称与批次年度仍表示本次管理批次，不替代指标年度。

只有2025年收入而规则要求2024年时，不会自动替代；只提供2024年但缺少2023年基数时，仍报基数缺失。文件没有年份标识时，按规则对应的当前／上一年角色匹配；存在多个候选年度时转为确认，不一列多用。

验证：`tests/test_rule_years.py` 覆盖短年份、不同批次年度、混合指标年度、缺失不替代、相对表头、默认摘要迁移、结构化方案一致性，以及解析→发布→上传→校验→计算→追溯→导出全链路。旧“指定年份与批次不同就阻止计算”的行为已被本规则替代。
