## 样例 1 · 经营增长表现

已有来源提示：revenue

别只看今年挣了多少，也看比去年长了多少：先用今年收入排一遍、用同比增幅再排一遍，各按名次给分。把两项得分各按一半合起来，再按综合分从高到低排一遍给分。同比就是今年减去年再除以去年绝对值，增减方向保留。

## 样例 2 · 收入／增幅

两个受支持方案均额外使用当年值5、上年值10的独立样例，验证实际计算的增幅为-0.5，未把下降转成正数。完整实际返回及引擎断言记录见 [验收证据](evidence/semantic-live-checks.json)。
