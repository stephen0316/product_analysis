# 文件映射三层保障

1. 先运行本地规则匹配（当前模型原始字段名、年度、已支持的表格布局）。明确匹配不调用 AI。单份文件可提供部分输入，缺少其他文件负责的输入不等于匹配失败。
2. 无可用匹配、工作表或同字段候选列有歧义时，才调用 Gemini。每份文件最多一次，20 秒超时；只提交文件名、工作表名、候选表头、模型输入和规则，不提交数据行或整份文件。沿用 GEMINI_API_KEY/GEMINI_MODEL 配置。
3. AI 未配置、服务失败、置信度低于 0.9、有待确认问题、返回无效列/指标/年度，均保留文件并提示手动调整用途、计算依据。AI 不能覆盖规则已确认的列，也不能把排名或增幅等派生列当原始输入。

来源记录保存 mapping_method、mapping_note、ai_attempted；AI 成功另保存 ai_confidence。人工保存映射记录为手动确认。读取批次、重复上传、人工调整不触发 AI。

多文件同一字段的数值冲突仍由现有数据校验和来源选择处理，AI 不自动选值、不改数值，也不改变模型公式。高置信度不代表绝对正确，自动采用的映射仍可在文件行查看依据并人工调整。
